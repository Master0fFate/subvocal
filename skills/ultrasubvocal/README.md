# ultrasteno

Steno, tightened: no note or plan lines, an alias at the first mention of any
multi-token term, one-word keys, no articles, pronouns or auxiliary verbs, and
short lines. Layered on top of `steno`: the hooks inject both, ultrasteno last.

```
/steno ultra      (or /ultrasteno)
```

See [`SKILL.md`](./SKILL.md) and [`docs/HONEST-NUMBERS.md`](../../docs/HONEST-NUMBERS.md).
